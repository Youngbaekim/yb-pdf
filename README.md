# YB-PDF

개인용(비상업) PDF 읽기·편집 앱 (PWA, 서버 없음 — 모든 처리는 이 기기 안에서만)

## 실행 방법 (PowerShell)

```
cd C:\dev\yb-pdf
npm install      # 처음 한 번만 (pdf.js 보조 파일도 함께 준비됨)
npm run dev      # 개발 서버 실행 → 화면에 나오는 주소를 브라우저로 열기
```

- 종료: PowerShell 창에서 `Ctrl + C`
- 배포: `main` 브랜치에 올리면 GitHub Actions가 자동으로 GitHub Pages에 배포 (https://youngbaekim.github.io/yb-pdf/)
- 새 버전 안내를 띄우려면 `public/sw.js`의 `VERSION`과 `src/main.js`의 `VERSION`을 함께 올린 뒤 배포

## 기능 (v0.10.0)

| 구분 | 내용 |
|---|---|
| 열기·저장 | 열기(Ctrl+O)·끌어다 놓기·최근 파일(시작 화면 한 줄 목록 50개 + 더 보기 30개씩, 최대 300개 보관), **Ctrl+S 같은 파일에 덮어쓰기**, 다른 이름으로 저장, 설치 앱에서 탐색기 '연결 프로그램' |
| 찾기 | Ctrl+F → 오른쪽 찾기 창, 띄어쓰기 무시·대소문자 무시 체크박스(기본 켬), 그림 속 글자(OCR: 찾지 않음/그림만 있는 쪽/모든 그림, 한글+영문, 인터넷 불필요), 결과마다 앞뒤 문맥 3줄, 누르면 그 위치로 이동해 강조, Enter·F3 다음 결과 |
| 쪽 편집 | '쪽' 탭에서 Ctrl+클릭(하나씩)·Shift+클릭/끌기(범위)·Ctrl+A로 여러 쪽 선택 → 삭제(Delete)·복사(Ctrl+C)·잘라내기(Ctrl+X)·붙여넣기(Ctrl+V — 쪽 **사이**를 누르면 그 자리, 아니면 선택한 쪽 뒤)·복제(Ctrl+D)·새 탭으로 꺼내기, 오른쪽 클릭 메뉴(앞/뒤에 붙여넣기). 주석도 함께 옮겨지고 Ctrl+Z로 되돌리기. 복사한 쪽은 다른 탭·다른 창(분리한 탭)에도 붙여넣기 가능 |
| 책갈피 | 왼쪽 메뉴 '책갈피' 탭: 나무형(처음엔 1단계만 펼침), 누르면 이동, 지금 보는 장 강조, 쪽 번호 표시, 모두 펼치기/1단계만. **직접 만들기·고치기(v0.10)**: ＋ 추가·Ctrl+B(지금 보는 위치, 글자를 골라 두면 그 글자가 제목), 이름 바꾸기(F2·두 번 누르기), 위치를 지금 보는 곳으로, 하위 추가, 단계(Alt+←/→)·순서(Alt+↑/↓·끌어 놓기), 삭제(Delete), Ctrl+Z. 저장하면 PDF 표준 책갈피로 기록(다른 뷰어에서도 보임). 쪽을 지우거나 끼우면 책갈피 쪽 번호도 따라감 |
| 보기 | 1쪽 / 2쪽 보기, 2쪽 보기의 **표지 단독(공백) 켜기·끄기**, 폭·쪽 맞춤, 확대·축소(Ctrl+휠·두 손가락), 쪽 미리보기, 전체 화면(F11·머리줄 단추) |
| 메뉴 | 왼쪽 접이식 패널(도구·쪽·주석·파일, 머리줄 왼쪽 스위치로 열고 닫기), 도구 줄(오른쪽 ↔ 맨 왼쪽 위치 전환), 너비 조절, 다크 모드 |
| 여러 문서 | 두 번째 PDF부터 상단 탭으로 열기, 탭 끌어 순서 변경, 창 밖에 놓으면 새 창으로 분리, 다른 창의 탭 줄에 놓으면 그 창으로 이동, 오른쪽 클릭 메뉴(새 창으로 옮기기·닫기), 설정으로 '새 PDF는 새 창으로' |
| 주석 | 형광펜(글자 선택·자유), 펜(필압), 메모, 텍스트 상자, 지우개, 이동·크기 조절·복제, 실행 취소 |
| 텍스트 수정 | 낱말·문장을 선택 → 바탕색으로 덮고 새 글자 기록 (바탕·글자색 자동 추출) |
| 서명 | 서명 패드·이미지 서명(흰 바탕 자동 제거), 서명 목록 저장, 끌어서 배치·크기 조절 |
| 합치기 | 여러 PDF를 고르거나 끌어다 놓기 → 순서 조정 → 완료 시 저장 위치·이름 지정 (열린 문서는 주석 포함) |

## Windows 설치판 (v0.3.0~)

| 항목 | 내용 |
|---|---|
| 설치 파일 | `YB_C_YB-PDF_Setup_버전.exe` 하나 (인터넷·Node.js 불필요, 관리자 권한 불필요 — 사용자 단위 설치) |
| 만들기 | `npm run dist` → `release` 폴더에 설치 파일 생성 후 **`C:\Users\USER\OneDrive\# SW Setup_YB_C`에 복사(같은 앱의 이전 버전 설치 파일은 삭제)** |
| 시험 실행 | `npm run app` (설치 없이 데스크톱 창으로 실행) |
| 파일 연결 | 설치하면 PDF '연결 프로그램' 목록에 YB-PDF 등록 → 탐색기에서 더블클릭하면 실행 중인 창에 새 탭으로 열림 |
| 저장 | 연 파일 경로에 바로 덮어쓰기 (임시 파일에 먼저 쓴 뒤 바꿔치기) |
| 업데이트 | 새 설치 파일을 실행하면 덮어 설치 (설정·서명 목록 유지) |
| HTML 열기 (v0.7.0~, 설치판 전용) | HTML 파일을 열기·끌어다 놓기 하면 크롬 엔진으로 PDF 변환(@page·쪽 나눔·배경색 반영, 글자는 그대로 글자) → 새 탭. Ctrl+S 하면 HTML과 같은 폴더를 기본 위치로 저장. 변환은 앱과 분리된 숨은 창에서 (HTML 스크립트가 PC 파일에 접근 못 함) |

## 저장 방식

- 주석은 **표준 PDF 주석**(Highlight·Ink·Text·FreeText·Stamp)으로 기록하고 외형을 직접 그려 넣음 → Acrobat·엣지·크롬 등에서도 같은 모양
- 주석마다 원본 데이터를 함께 넣어 두므로 YB-PDF로 다시 열면 그대로 고치거나 지울 수 있음
- 한글은 나눔 글꼴에서 **쓴 글자만 추출**해 넣음 (HarfBuzz) → 파일 크기 증가 최소화

## 알려진 한계

- 텍스트 수정은 원래 글자를 '덮고 새로 쓰는' 방식: 원래 글자는 파일 안에 남아 있음(검색·복사 시 나타날 수 있음)
- 암호가 걸린 PDF는 열 때 암호 입력 창이 뜨고(틀리면 다시 물음), 연 뒤에는 보기 전용(주석 저장 불가)
- 그림 속 글자 인식(OCR)은 찾기에만 쓰이며 정확도가 완전하지 않음(색 바탕 위 작은 흰 글씨, 영문 'AI' 등은 틀리기 쉬움). 인식 결과는 문서(탭)를 열어 둔 동안만 보관 — 다시 열면 다시 인식
- 저장 시 파일 전체를 다시 쓰므로, 전자서명(공인인증)이 들어 있는 PDF는 그 서명이 무효가 됨
- 책갈피를 고치거나 쪽을 편집해 저장하면 문서의 책갈피를 새로 씀: 원래 책갈피의 세부 동작(이름 붙은 목적지·글자 크기 맞춤 방식 등)은 '그 위치로 이동'으로 단순화됨
- 덮어쓰기 저장은 PC의 크롬·엣지에서 지원 (그 밖의 환경은 내려받기로 저장)
